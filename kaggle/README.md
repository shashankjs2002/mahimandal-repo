# Dataset documentation update

`DESCRIPTION.md` contains the updated Kaggle description. `dataset_card.json`
records the corrected reflectance16 description and scoring support.

The 4,800 published pairs, original manifest, protocol, split CSVs, TIFFs and
their existing checksums remain the scientific release. This update concerns
documentation and supporting evidence. The GitHub repository holds the revised
paper, paired-score analysis, archived three-seed results and identified-fill masks.

Edit the existing Kaggle dataset description using `DESCRIPTION.md`. If updating
the downloadable dataset card, retain every existing image and frozen release
file in the new Kaggle version. A card-only folder must not be uploaded as a
replacement for the complete dataset. Preserve the current title, licence and
visibility. Record the resulting Kaggle version once publication succeeds.
